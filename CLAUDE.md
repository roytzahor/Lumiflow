# LumiFlow - Personal Financial Management

## Project Overview
LumiFlow is a financial management application built with **Next.js**, **NextAuth**, and **Prisma**. It focuses on automating financial tracking and visualization.

## Tech Stack
- **Framework:** Next.js 15 (App Router)
- **Language:** TypeScript
- **Auth:** NextAuth.js
- **Database:** PostgreSQL via Prisma ORM
- **Styles:** Tailwind CSS
- **Tools:** Docker Compose, Cypress

## Coding Standards
- Use functional components and React Hooks.
- Prefer `lucide-react` for icons.
- Strict TypeScript: No `any` type.
- Follow a modular architecture: business logic in `lib/`, UI in `components/`.

## Key Commands
- `yarn dev` - Start development server
- `npx prisma studio` - Open database GUI
- `yarn test` - Run tests
